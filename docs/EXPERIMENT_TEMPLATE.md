# 实验记录模板

- 实验 ID / 标题：
- 问题与假设：
- 源 commit / 文件：
- 游戏版本、平台、交通侧：
- Mod 名称、ID、版本、配置、依赖：
- 存档与原始备份（不公开敏感数据）：
- 几何参数及单位、节点/路段/车道关系：
- 复现步骤与对照组：
- 预先确定的通过条件：
- 实际结果及证据文件：
- 状态（默认 NOT_TESTED）：
- 保存重载/升级/卸载验证：
- 局限、失败与下一步：
- 全仓文档影响记录：

- 需求ID/验收Case：
- 输入支持域、full/partial基准及禁止流向：
- 源道路快照与Apply前重新核验：
- 几何容差、单位、来源及离散后误差：
- 中英文本、单位切换与可访问性：

- 服务/系统型、下游端部与排队影响区：
- 需求/完成出行/未完成或消失/排队/观察窗口及不可观测项：
- 游戏建造维护费用与性能：实际来源或UNKNOWN：

- 场地B/禁建区/高程基准/锁定主线：
- footprint定义及基线、总面积/场地内占比/越界/新增移除保留：
- 预设实际参数、硬/软约束、归一化尺度：
- 候选集、搜索停止原因与复现设置（不编种子或全局最优）：
